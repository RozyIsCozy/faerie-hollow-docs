How settings work¶

Faerie Hollow's settings come in two tiers, so the ones most server owners want are never lost among the fine tuning:

File What it holds Who it belongs to
faeriehollow-server.toml Start here. The essentials: gathering, speech bubbles, the highest bond level, the realm's portals and foes, foe strength, structures switched off, and percentages that scale whole groups of finer settings at once The world, or the server. In multiplayer, everyone gets the server's values.
faeriehollow-server/familiars.toml The bond and its levels, gathering, the satchel, speech, every familiar power and every kind of familiar, bewitched creatures, Whispurrs, the Alraune, Buzzybees and faerie wings The world, or the server
faeriehollow-server/creatures.toml Each foe and boss (health, damage, how it fights) and the realm's gentle creatures, mounts and merchants The world, or the server
faeriehollow-server/realm.toml The Faerie Portal, everything the realm brings near its players and how often, its doings (faires, bells, wells, bathhouses), tea parties, mushrooms, plants and snow The world, or the server
faeriehollow-server/world.toml Which of the realm's structures and features generate, and the mod's loot in vanilla's chests The world, or the server
faeriehollow-server/items.toml The Bewitched Cauldron and its brews, the Faerie Altar, the wedding cake, gear, food, trees and faerie houses The world, or the server
faeriehollow-client.toml Your own options: music, particles, speech bubbles, accessibility Each player, for themselves.

Every setting is listed, with its default and allowed values, in the settings reference and Client settings and keys. For common changes, copy a ready-made setup.

Percentages stack

A percentage on the front page (like foes.healthPercent) multiplies the matching setting in a topic file (each foe's own healthPercent in creatures.toml). 100 changes nothing, so a file left alone plays exactly as the mod was made.

World Settings, in game¶

If you host the world (single player, or a world you open to LAN), you can change its server settings without opening a file. While playing, press Esc, then Mods, select Faerie Hollow, press Config, and then World Settings... at the bottom of the screen.

  • Plain controls first. The Foes, Wildlife, Familiars, Whispurrs and Realm tabs cover the changes most players want. Advanced has every server setting, with times given in seconds rather than ticks.
  • For this world alone. What you save is kept in the world's own folder, in faeriehollow/world-settings.json, and goes wherever the world goes. The settings files are left as they are, so your other worlds keep theirs.
  • They win over the files. A setting you change here uses this world's value; every other setting follows the files as usual. Reset Tab, or a setting's own reset button, puts it back to the file's value.
  • Changes apply as soon as you save, for everyone in the world: players on your LAN get them at once. The one exception is the realm's wildlife (how often each creature comes), which changes the next time the world opens; the panel offers to save and quit to the title screen so you can open it again.
  • New Worlds... makes this world's settings the ones worlds you create from now on start with. That choice is kept in the game's config/faeriehollow-new-worlds.json. Worlds you already have keep their own.

Only the host sees it

Players visiting your LAN world, and players on a dedicated server, never see the panel: a server's settings stay in its admin's hands, in the files. A world taken to a dedicated server keeps its own World Settings there, laid over that server's files.

Where the files are¶

The game makes each file, filled with the defaults, the first time it needs it: the client file when the game first starts with Faerie Hollow, the server files when a world (or server) first starts. The topic files are in a faeriehollow-server folder beside faeriehollow-server.toml.

File Location
Server settings config/faeriehollow-server.toml and config/faeriehollow-server/ in your game (or server) folder. Apply to every world.
Server settings for one world Copy a file into that world's serverconfig/ folder (a topic file into serverconfig/faeriehollow-server/). That copy then wins for that world.
Client settings config/faeriehollow-client.toml
File Location
Server settings serverconfig/faeriehollow-server.toml and serverconfig/faeriehollow-server/ inside each world's folder (saves/<world>/serverconfig/ in single player, world/serverconfig/ on a server). Each world has its own.
Defaults for new worlds Put the files in the game's defaultconfigs/ folder (topic files in defaultconfigs/faeriehollow-server/). New worlds start with a copy of them.
Client settings config/faeriehollow-client.toml

In single player

Your world is also a "server", so its server settings work exactly as they do on a dedicated server. On Forge, open the world once so its serverconfig folder is made, then edit the files there.

Editing the files¶

The files are plain text in the TOML format. Open them in any text editor.

# A line starting with # is a comment, ignored by the game.
[familiars]
    gathering = true
    maxBondLevel = 10
  • Changes apply as soon as you save. You don't need to restart the game or server: the game plays by the new values at once (players' satchel screens may show new level numbers only when they next join). A few settings say they only affect things made from then on, such as new tea parties, new trees, or land generated from then on. How often each of the realm's creatures comes ([spawns.wildCreatures.weights] in realm.toml) is read as the world opens, so it changes the next time the world or server starts.
  • Keep each setting in its [section], in its own file. A setting moved out of its section (or into another file) is treated as unknown and reset.
  • Numbers outside the allowed range are pulled back in. Set maxBondLevel = 500 and the game uses 100, its highest allowed value, and writes that back into the file. A value of the wrong kind (text where a number belongs) goes back to the default.
  • Decimals only where the default has one. Settings whose default has a decimal point (like 12.0) accept decimals; the others expect whole numbers.
  • To reset a file, delete it. The game writes a fresh one with the defaults next time it loads the world.

Ticks, chances and caps¶

Many settings share the same units:

Ticks
The game's clock: 20 ticks = 1 second. So 1200 ticks is a minute and 24000 ticks is a whole Minecraft day. The settings tables show the real time next to each default.
Chance (percent)
0 never, 100 every time.
Percent (a setting ending in Percent)
A multiplier: 100 changes nothing, 200 doubles, 50 halves.
enabled
Everything the realm brings near its players now and then (goblins, reapers, Whispurrs...) has the same settings in realm.toml: enabled, intervalTicks (how often it has a chance), chance and, where there is one, cap. enabled = false switches one off; hostileSpawns = false on the front page switches every foe off at once.
Cap
The most there can be near a player at once. When the cap is reached, no more come until some leave.
Min and max pairs
Familiar settings often come in pairs (radiusMin, radiusMax): the first value is what a familiar has at bond level 1, the second at the highest level, with the levels between scaled evenly.

For modpack makers¶

To ship your own defaults:

  • NeoForge 1.21.1: include your config/faeriehollow-server.toml and config/faeriehollow-server/ in the pack.
  • Forge 1.20.1: include them as defaultconfigs/faeriehollow-server.toml and defaultconfigs/faeriehollow-server/, so each new world starts with your values. (A file in config/ is not read for server settings on Forge.)

Include only the files and settings you change if you like: anything missing is filled in with its default.
