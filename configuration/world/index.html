World generation settings¶

Every setting in faeriehollow-server/world.toml, in the order it appears in the file. World generation settings apply to land generated from then on: what is already generated stays as it is. Structures can also be switched off by name on the front page (disabledStructures).

Structures others keep clear of

Switch a structure off here, never by deleting its data in a datapack: other structures keep their distance from some of them (the faerie hamlets above all), and that only works while the structure's data is there. Where structures generate and how far apart is datapack data: see World generation.

[structures]¶

The realm's structures. Each can be switched off (as can any on the front page's disabledStructures). Their spacing and biomes are datapack data: see the mod's docs/CONFIG.md.

Setting Default Allowed What it does
densityPercent 100 0 to 100 How many of the realm's structures generate, as a percentage of those that would: each spot one would stand on is kept or passed over by the world's seed, so the same world always keeps the same ones. It can only make them rarer (their spacing is datapack data). 0 generates none. Applies to new chunks only.

[structures.faerieBridge]¶

Setting Default Allowed What it does
enabled true true / false Whether they generate. New chunks only.

[structures.faerieHamlet]¶

Rings of faerie houses round a little green. Twenty-odd other structures keep their distance from the hamlets' spots, so switch hamlets off here (or on the front page) rather than by removing their structure set with a datapack, which would leave those others pointing at a set that is gone. ("faerie_hamlet" on the front page's disabledStructures.)

Setting Default Allowed What it does
enabled true true / false Whether they generate. New chunks only.

[features]¶

What generates in the land and grows from saplings.

Setting Default Allowed What it does
limbsAndRoots true true / false Witch's Willows and faerie trees grow as Dynamic Trees draws trees: limbs tapering from the trunk to their leaves, and roots spreading over the ground from the trunk's foot. false grows their limbs of plain logs, as vanilla's trees' branches are, and no roots. Trees already grown keep the shape they grew in.
faerieRings true true / false Faerie rings of mushrooms grow in the realm's meadows and woods (satyrs hold their revels in them). New chunks only.
treehouses true true / false Faerie treehouses grow in the realm's great trees, and Toadstool Pods on the Glowcap Knolls. New chunks only.
teaParties true true / false Faerie tea parties are laid out now and then on the realm's land (realm.toml's teaParties section says how). New chunks only.
realmQuartzOre true true / false Nether quartz ore lies in the realm's stone, which the Overworld has none of. New chunks only; nothing else in the ground changes either way.

[loot]¶

The mod's loot in vanilla's chests and fishing.

[loot.crownPieces]¶

Broken Crown Pieces added to vanilla's loot. The realm's relic chests (Titania's court, Oberon's hall, the grand abbey and the drowned palace) hold them whatever these say, so the Faerie Altar can still be woken while those structures generate. crownPiecesInVanillaLoot on the front page switches both of these off at once. How likely each is, chest by chest, is datapack data (the mod's loot modifiers).

Setting Default Allowed What it does
inChests true true / false They turn up in vanilla's chests: Nether fortresses, dungeons, desert and jungle temples, ancient cities, End cities, bastions' hoglin stables and strongholds.
whileFishing true true / false One is now and then fished up in open water, in place of the catch.
