Sounds and music¶

Replace a sound by adding your own assets/faeriehollow/sounds.json with the events you change, set to "replace": true, and your sound files beside it:

assets/faeriehollow/sounds.json
{
  "item.fey_bell.ring": {
    "replace": true,
    "sounds": ["faeriehollow:item/my_bell"]
  }
}

That plays assets/faeriehollow/sounds/item/my_bell.ogg (an Ogg Vorbis file) whenever the Fey Bell rings. Events you don't list keep the mod's sounds.

To silence an event, replace it with an empty list: "sounds": [].

For long tracks, mark each sound "stream": true, as vanilla does for music, so the game doesn't load the whole file at once:

assets/faeriehollow/sounds.json
{
  "music.realm.faerie": {
    "replace": true,
    "sounds": [{ "name": "faeriehollow:music/my_meadow_theme", "stream": true }]
  }
}

Seasonal music¶

The realm's Halloween music (25th to 31st October) and Christmas music (21st to 31st December) come in a resource pack of their own, Faerie Hollow Seasonal Music, kept apart from the mod so the tracks can be full quality. Add it in Options > Resource Packs (one pack works for both Minecraft versions); in their seasons its tracks play instead of the realm's own. Players can still turn them off in the options screen.
