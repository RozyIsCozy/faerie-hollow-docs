Servers and multiplayer¶

Both sides need the mod¶

Faerie Hollow adds blocks, items, creatures, a dimension and an inventory slot, so the server and every player must have it installed, in the same version. A player without it can't join. Optional extras (Curios) follow their own rules: Curios also has to be on both sides when it's used.

Who controls what¶

Setting Lives on Who changes it
Familiars, gathering, the realm's creatures and dangers, trees, the portal The server (server settings) The server admin. Players get the server's values automatically. A LAN world's host can also change them in game (World Settings).
Music, particles, speech bubbles, accessibility Each player's game (client settings) Each player, for themselves.
Keybinds Each player's game Each player.
Datapacks (tags, custom familiars, brews, loot) The world's datapacks folder The server admin.
Resource packs (textures, sounds, speech lines) Each player's game, or the server's resource pack Each player, or the server can offer one.

Changing settings on a running server¶

Edit the server config files and save them. Faerie Hollow picks the new values up straight away, with no restart: the game plays by them at once. The satchel screen's level numbers on players' own screens may only catch up when they next join. See Where the files are.

Things players share on a server¶

  • Familiars are their owner's alone. Other players can't pet, feed, name, lead, ride, saddle, shear or dye someone else's familiar, or take what it holds. They can milk someone's cow, mooshroom or goat familiar.
  • Gathering can be paused per player with a key (G), and switched off for everyone by the admin (gathering = false on the front page).
  • Sleeping counts across the overworld and the Faerie Realm together, by the playersSleepingPercentage game rule. See Game rules.
  • Night visitors come near each player. On a busy server, bombers, reapers, serpents, Whispurrs and brew foes are capped near each player (each spawn's cap), and each goblin camp holds one pack, which a cleared camp gets back only after a day (refillTicks), so ten players in one place don't get ten times the foes. See Faerie Realm settings.
