Tag reference¶

Every tag Faerie Hollow ships, grouped by what it does, with what it holds out of the box. Each is listed by its ID; the file path follows from it. For example #faeriehollow:treats/cat, an item tag, lives at:

  • 1.21.1: data/faeriehollow/tags/item/treats/cat.json
  • 1.20.1: data/faeriehollow/tags/items/treats/cat.json

New to tags? Start with Adding to a tag, or replacing it.

Tip

Use the search (S) with part of a tag's name, like treats or shunned, to jump straight to it.

Where creatures spawn¶

These biome tags decide where each creature can spawn naturally. Add a biome (yours or another mod's) to let a creature live there too; replace the tag ("replace": true) to move it entirely. Creatures still need the right ground, light and time of day, just as they do in their own biomes. Bewitched creatures (Toadstool Calves, Jackalopes, Truffle Hogs, Hexwool, Mooncalves, Mossbacks, Horned Owls, Grimalkins, Dire Wolves, Blue Moon Hens, Witch's Toads, Hedgefoxes, Blackhorn Goats, Vampire Bats and Hex Newts) are vanilla animals the realm bewitches: they are only bewitched in the realm's own biomes (#faeriehollow:faerie_realm), so a biome added elsewhere gets the plain vanilla animal. Faeries, unicorns and the deer are themselves anywhere.

When changes apply

Changes apply after restarting the world or server.

Where night visitors come, and where they keep away¶

These tags steer the creatures that come to players in the Faerie Realm by night, and the places foes keep away from. The server config sets how often each comes; these tags set where. They only act in the realm: biomes or structures elsewhere added to them bring no visitors.

When changes apply

Changes apply after restarting the world or server.

Where structures generate¶

When changes apply

Crafting and building groups¶

Groups the mod's recipes and blocks use. Add items to let them stand in for the mod's own in recipes (for example another mod's seeds in Fey Food).

When changes apply

Changes apply after /reload.
