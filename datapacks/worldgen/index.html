World generation¶

The Faerie Realm¶

The realm is its own dimension, faeriehollow:faerie_realm. Players reach it through a Faerie Portal in a Witch's Willow; with commands you can go straight there:

/execute in faeriehollow:faerie_realm run tp @s ~ 100 ~

Placing features by command¶

Some of the realm's small set pieces can be placed where you stand, handy for builds and testing:

Feature Command
A faerie tea party /place feature faeriehollow:faerie_tea_party
A faerie ring /place feature faeriehollow:faerie_ring
A faerie treehouse /place feature faeriehollow:faerie_treehouse

For pack makers building their own worldgen¶

The Witch's Willow is the faeriehollow:witch_willow configured feature, which you can place, or override with a file of your own. Its parts can be used in your own tree features: the faeriehollow:willow_trunk_placer trunk placer, the faeriehollow:cloud_foliage_placer foliage placer, and the faeriehollow:hanging_tresses and faeriehollow:surface_roots tree decorators.

Old names

witch_tree, limbed_trunk_placer, crown_foliage_placer and witch_tree_growth are from earlier versions and no longer exist. Use the names above.
