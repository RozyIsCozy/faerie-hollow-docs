The mod's loot tables¶

Replace any of these with a file at the same path in your pack to change what it gives. They're standard Minecraft loot tables: data/faeriehollow/loot_table/<name>.json on 1.21.1, data/faeriehollow/loot_tables/<name>.json on 1.20.1. Apply changes with /reload.

Foraging familiars

faeriehollow:gameplay/familiar_forage is what a foraging familiar (fox, chicken, frog...) finds. A custom familiar can name a different table in its forager ability.

Broken Crown Pieces in vanilla loot¶

Broken Crown Pieces turn up in vanilla chests and fishing, added by these loot modifiers:

Modifier Adds a Broken Crown Piece to Chance
broken_crown_piece/chests/ancient_city minecraft:chests/ancient_city 0.1074 (about 1 in 9)
broken_crown_piece/chests/bastion_hoglin_stable minecraft:chests/bastion_hoglin_stable 0.08 (about 1 in 12)
broken_crown_piece/chests/desert_pyramid minecraft:chests/desert_pyramid 0.1566 (about 1 in 6)
broken_crown_piece/chests/end_city_treasure minecraft:chests/end_city_treasure 0.0885 (about 1 in 11)
broken_crown_piece/chests/jungle_temple minecraft:chests/jungle_temple 0.0857 (about 1 in 12)
broken_crown_piece/chests/nether_bridge minecraft:chests/nether_bridge 0.2351 (about 1 in 4)
broken_crown_piece/chests/simple_dungeon minecraft:chests/simple_dungeon 0.1862 (about 1 in 5)
broken_crown_piece/chests/stronghold_corridor minecraft:chests/stronghold_corridor 0.0165 (about 1 in 61)
broken_crown_piece/gameplay/fishing minecraft:gameplay/fishing 0.00556 (about 1 in 180)

Each modifier lives at data/faeriehollow/loot_modifiers/<modifier>.json (the same path on both versions). To change how often a piece turns up, put a copy in your pack with a different chance. To stop it turning up in one place, set that copy's chance to 0. For example, to make pieces far more common in dungeon chests (the mod ships 0.1862):

data/faeriehollow/loot_modifiers/broken_crown_piece/chests/simple_dungeon.json
{
  "type": "faeriehollow:add_item",
  "conditions": [
    { "condition": "neoforge:loot_table_id", "loot_table_id": "minecraft:chests/simple_dungeon" },
    { "condition": "minecraft:random_chance", "chance": 0.5 }
  ],
  "item": "faeriehollow:broken_crown_piece"
}
data/faeriehollow/loot_modifiers/broken_crown_piece/chests/simple_dungeon.json
{
  "type": "faeriehollow:add_item",
  "conditions": [
    { "condition": "forge:loot_table_id", "loot_table_id": "minecraft:chests/simple_dungeon" },
    { "condition": "minecraft:random_chance", "chance": 0.5 }
  ],
  "item": "faeriehollow:broken_crown_piece"
}

A chest gets at most one piece. A piece fished up (in open water only) comes up instead of the catch, and Luck of the Sea doesn't change the odds.
