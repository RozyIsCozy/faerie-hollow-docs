Datapack basics¶

A datapack can change a great deal of Faerie Hollow without touching the mod: where creatures and structures appear, what familiars eat, which mobs can become familiars, what the cauldron brews and what chests hold.

You want to... Use
Let a creature spawn in more biomes, or a structure generate in more places Tags
Give familiars new treats, or make faeries visit your decorations Tags
Make any mob (modded ones too) a familiar, with its own abilities and voice Custom familiars
Add your own Bewitched Cauldron brews Cauldron brews
Change what chests, fishing and the mod's gifts give Loot
Find the mod's structures, biomes and dimension IDs World generation

Making a datapack¶

  1. In your world's folder, open datapacks/ and make a folder for your pack, for example datapacks/my_faerie_tweaks/.

  2. Inside it, make a pack.mcmeta:

    { "pack": { "pack_format": 48, "description": "My Faerie Hollow tweaks" } }

    { "pack": { "pack_format": 15, "description": "My Faerie Hollow tweaks" } }

  3. Add your files under data/, following the paths on these pages.

  4. Run /reload, or restart, depending on what you changed (see below). /datapack list shows whether it loaded.

The two versions use different folder names¶

Minecraft 1.21 renamed several datapack folders from plural to singular. Use the names for your version:

What 1.21.1 1.20.1
Block tags tags/block/ tags/blocks/
Item tags tags/item/ tags/items/
Entity tags tags/entity_type/ tags/entity_types/
Recipes recipe/ recipes/
Loot tables loot_table/ loot_tables/
Biome and structure tags tags/worldgen/biome/, tags/worldgen/structure/ the same
Loader-wide tags c: namespace (data/c/tags/...) forge: namespace (data/forge/tags/...)

One pack for both versions

A pack can hold both sets of folders: each version reads its own and ignores the other's. So neither version calls it a pack for another, give 1.20.1's format as pack_format and list both in supported_formats (which 1.21.1 reads and 1.20.1 ignores):

{ "pack": { "pack_format": 15, "supported_formats": [15, 48], "description": "My Faerie Hollow tweaks" } }

Adding to a tag, or replacing it¶

A tag file in your pack is merged with the mod's by default, so you only list what you're adding:

data/faeriehollow/tags/worldgen/biome/spawns_faeries.json
{
  "values": [
    "minecraft:flower_forest",
    "minecraft:cherry_grove"
  ]
}

To replace the mod's list entirely (to remove entries, or empty it), add "replace": true:

data/faeriehollow/tags/worldgen/biome/has_structure/goblin_camp.json
{
  "replace": true,
  "values": []
}

For something from another mod that might not be installed, write the entry as { "id": "othermod:thing", "required": false } so the tag still loads without it.

When changes apply¶

You changed It applies
Item, block or entity tags After /reload
Custom familiars, cauldron brews, loot tables and loot modifiers After /reload
Biome or structure tags (spawns, haunts, music) After restarting the world or server
Where structures or ores generate After a restart, and only in land generated from then on

The Tag reference says which applies to each tag.
