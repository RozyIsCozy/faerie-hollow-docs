Cauldron brews¶

The Bewitched Cauldron's brews are ordinary datapack recipes, so a pack can add new ones or change the mod's own. A brew your pack adds appears in the Witch's Grimoire like any other.

Where it goes: data/<namespace>/recipe/<name>.json on 1.21.1, data/<namespace>/recipes/<name>.json on 1.20.1. Apply changes with /reload.

Example¶

Two Fey Food from three ingredients, brewed only by night:

data/my_pack/recipe/moonlit_fey_food.json
{
  "type": "faeriehollow:witch_brewing",
  "ingredients": [
    { "item": "faeriehollow:moonberries" },
    { "item": "minecraft:sugar" },
    { "tag": "c:seeds" }
  ],
  "result": { "id": "faeriehollow:fey_food", "count": 2 },
  "brewing_time": 100,
  "when": "night",
  "color": "#9a7fd1"
}
data/my_pack/recipes/moonlit_fey_food.json
{
  "type": "faeriehollow:witch_brewing",
  "ingredients": [
    { "item": "faeriehollow:moonberries" },
    { "item": "minecraft:sugar" },
    { "tag": "forge:seeds" }
  ],
  "result": { "item": "faeriehollow:fey_food", "count": 2 },
  "brewing_time": 100,
  "when": "night",
  "color": "#9a7fd1"
}

The result is written differently in each version

1.21.1 names the result's item with "id"; 1.20.1 with "item". This follows each Minecraft version's own recipe format.

Fields¶

Field Required Default What it does
type yes Always faeriehollow:witch_brewing.
ingredients yes Up to six items or tags, in any order. Each goes in once.
result yes What the brew makes.
brewing_time 100 How long it brews, in ticks (20 ticks = 1 second).
when any hour "day" or "night": it only brews then.
color "#c79bff" (the cauldron's own violet) The color of the water while it brews, as "#rrggbb".
ladled false true for a drink. A ladled brew stands in the cauldron, one serving per measure of water, and each empty glass bottle used on it takes a serving. Its result must then have a count of 1 (one bottle), or the recipe doesn't load.

How the cauldron chooses¶

  • A cauldron brews as soon as its water holds exactly one brew's ingredients.
  • When one brew's ingredients are all part of a bigger brew, the smaller one is made first, unless something only the bigger one takes goes in before. Avoid making a new brew's ingredients a subset of another's, or players may never reach the bigger one.
  • Buckets and bottles only ever fill and empty the cauldron, so no brew can use them as ingredients.
