Custom familiars¶

Any mob, modded ones included, can become a familiar with one JSON file in a datapack.

Where it goes: data/<namespace>/faeriehollow/species/<name>.json (the same path on both versions). Use your own namespace for new familiars. Apply changes with /reload.

To change one of the mod's own familiars, put your file at that familiar's own path, in the faeriehollow namespace, so it replaces the mod's: for the cat, data/faeriehollow/faeriehollow/species/cat.json. A file for the same mob under any other name doesn't replace the mod's; it clashes with it (see When a file is wrong).

A first example¶

This makes a tamed donkey a familiar that keeps creepers away, fed with treats from a tag of your own:

data/my_pack/faeriehollow/species/donkey.json
{
  "entity": "minecraft:donkey",
  "bond": "owned",
  "treats": "my_pack:donkey_treats",
  "pickup_radius": 1.0,
  "pickup_speed": 1.0,
  "abilities": [
    { "type": "faeriehollow:creeper_ward", "radius": { "min": 6, "max": 16 } }
  ]
}
data/my_pack/tags/item/donkey_treats.json (1.21.1; tags/items/ on 1.20.1)
{ "values": ["minecraft:apple", "minecraft:golden_carrot"] }

Fields¶

Field Required Default What it does
entity yes The mob, by ID. A file for a mob from a mod that isn't installed is skipped.
bond owned How the player must have won the mob over before bonding (see below).
treats none An item tag of the treats it eats. Without one it can't be fed treats.
pickup_radius 1.0 Multiplies the gathering reach (0.1 to 10).
pickup_speed 1.0 Multiplies how often it gathers (0.1 to 10).
affection 1.0 How fast its bond grows (0.1 to 10). 0.25 takes four times as long, as Titania's and Oberon's do.
faints false true for a familiar that fights. See below.
abilities none A list of abilities.
voice its own How it talks in speech bubbles. See Voice.

Bond types¶

bond A player can bond it when...
owned they tamed it (cats, wolves, parrots...).
trusted it trusts them (a fox trusts only the player who earned it; an ocelot, once trusting, trusts anyone).
liked they are its chosen player (allays).
rescued it was released from a bucket, by anyone (axolotls).
any always: any one of that mob can be bonded.

Fighters and the rest¶

A familiar with "faints": true joins its owner's fights (and only those). It can be hurt, and a blow that would kill it makes it faint and rest in its satchel for a while instead (companion.faintRecoveryTicks in the familiar settings). Every other familiar can't be hurt at all, never attacks anything, and is never attacked.

Abilities¶

Each ability is an object with a type and its own fields. Most number fields take either a single number, or { "min": a, "max": b }: the first at bond level 1, the second at the highest level, scaled evenly between. A few take a single whole number only, marked whole number below, and unlock_level is one too.

Every ability can also have:

  • unlock_level (1 to 1000, default 1): it only works from that bond level on (shown grayed out in the satchel until then). Its values are then scaled from that level to the highest.
  • hours (any, day or night, default any): it only works in those hours.
Ability type Fields (allowed values, default) What it does
faeriehollow:illuminate light (1-15, required) Sheds light where it is, as it goes (the light switched off for everyone by companion.faerieLight = false in familiars.toml; the whole power by powers.illuminate.enabled = false).
faeriehollow:creeper_ward radius (1-48 blocks, required) Keeps creepers away from its owner.
faeriehollow:guardian radius (1-48, required), damage_bonus (0-100, default 0) Fights for its owner. Only for a familiar that faints.
faeriehollow:lookout radius (1-64, required), interval (10-1200 ticks, default 100 → 40) Marks monsters near its owner, so they can be seen coming.
faeriehollow:forager chance (0-1, required), loot_table (default faeriehollow:gameplay/familiar_forage) Now and then finds something extra as it gathers.
faeriehollow:aquatic regeneration_level (whole number 1-100, default 5), breath (1-100, default 2 → 8) Helps its owner underwater: heals them there, their breath lasts longer, and at a full bond they can breathe water.
faeriehollow:tend_growth radius (1-32, required), pulses (1-64, required), name, favors (titania or oberon), bounty (0-1, default 0) Helps plants in #faeriehollow:monarch/tends grow.
faeriehollow:court_favour court (titania or oberon, required) Gives its owner the favor of Titania's or Oberon's court.
faeriehollow:royal_ward name (required), ward (near or far, required), radius (1-48, required) Monsters near its owner leave them be (near), or monsters far off never notice them (far).
faeriehollow:moonpath from (whole number of blocks, default 32) Shows motes leading home once its owner is this far away.
faeriehollow:queens_bower none Weaves a bower its owner can sleep in.
faeriehollow:love radius (1-32, required), pairs (1-16, required), every (200-72000 ticks, required), crowd (whole number 2-256, default 24) Now and then sets nearby animals breeding.
faeriehollow:midas count (1-64 a day, required), gildings (required) Turns items in its owner's inventory to gold once a day. gildings is a list of {"from": item, "to": item, "from_level": level} (from_level a whole number).
faeriehollow:lend_wings color (a faerie wings color, required), seconds (whole number 5-3600, default 60), cooldown (whole number 0-86400 seconds, default 300) Lends its owner faerie wings. Outside the realm, below a full bond, they catch the owner's falls for seconds at a time, every cooldown; in the realm, or at a full bond, they last as long as the familiar is out.

Voice¶

Every field is optional:

"voice": { "lines": "minecraft:cat", "sound": "minecraft:entity.cat.purr", "color": "#E39B4B" }
  • lines: whose speech-bubble lines it says, as an ID. Without it, a familiar says its own mob's lines. Lines are language keys you can add in a resource pack; see Speech bubbles and translations.
  • sound: the sound it makes as it speaks. Without it, its own ambient sound.
  • color: the edge color of its bubbles, as "#RRGGBB".

When a file is wrong¶

A file with a bad value (an unknown bond, a number out of range, an unknown ability, a malformed color) or a missing required field is skipped as a whole, never half-loaded, and the game log names the file and the problem.

A misspelt field name is not an error: it is ignored and that field keeps its default. If a setting seems to have no effect, check its spelling.

Only one file per mob is used. If two files are for the same mob, which one wins is not predictable (the log warns about it), so to change one of the mod's own familiars always use its exact path. See Troubleshooting.
